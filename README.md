# University of Delaware Website

## About the Project
This website was created as my final project for my CISC course at the University of Delaware. The purpose of the website is to introduce users to the University of Delaware and provide information about the school.

## Features
- Information about the University of Delaware
- Easy-to-use navigation
- Interactive website elements
- Organized layout to help users explore the university

## How to View the Website
1. Open the project files in this GitHub repository.
2. Download the website files.
3. Open the main HTML file in a web browser to explore the website.
